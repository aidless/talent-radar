一个本地优先的结构化自省工具：40 道题 × 10 维，把自评、行为证据与他人反馈分开呈现，再把结论压成可验证的具体行动。

GitHub 仓库 在线 Demo v1.0.0 Release

测评引擎

40 题交错覆盖 10 维；行为 / 反馈 / 自评三轨加权；结果页显示差距与并列敏感度，近并列不硬排第一。

本地导出

单文件 HTML、localStorage、雷达 SVG、1080×1440 分享 PNG、文字报告与 JSON 导出，无运行时依赖。

AI 追问协议

深度挖掘、反证官、落地三段 Prompt；一次一题追问事件，证据不足允许 0–3 项，不强行凑结论。

工程要点

  • 前端是零依赖单文件 HTML；Canvas 直绘分享卡，SVG 转 PNG，数据默认只留 localStorage。
  • serve.py 同源托管并反代 OpenAI-compatible 网关，解决 file:// 下 CORS 问题。
  • 匿名贡献默认关闭、二次确认；30 天窗口按 contributor_hash 去重，n≥500 ready，n<200 cut。
  • CI 跑 15 项 Python 与 6 项 JavaScript 检查；GitHub Pages 部署静态 Demo；Release 附带 product zip。

证据边界

静态 Demo 没有后端：AI 深挖与数据池接口需本地 serve.py。这是结构化自省工具，不是心理测评认证、心理诊断或信度效度已验证的产品。

真人验证包已就绪，但当前状态是「材料就绪、未招募、无结果」。数据池代码与阈值已实现，实际样本数尚未产生。

适合怎么讲

  • 一句话：把「我觉得」压成「我做过」，再用反证与 30 天实验验证。
  • 工程面：单文件离线引擎 + 双轨差距信号 + Canvas 导出 + 同源反代 + 默认关闭的隐私设计。
  • 产品面：从提示词想法走到开源仓库、CI、Pages Demo、Release 与发布文案的完整副线闭环。
